**Building a 2D Bike Simulator with JavaScript and Production-Grade CI/CD.**

I recently built a responsive 2D Bike Simulator game using JavaScript, taking it all the way from development to deployment with production-style CI/CD practices. I also used AI as a learning and productivity booster—mainly to speed up problem-solving—while still owning the overall design, logic, and final implementation.


**What the game includes:**

Multi-lane road logic with real-time collision handling
Infinite scrolling environment with a dynamic day/night mode
Level-based difficulty that increases as the game progresses
Support for both keyboard input and mobile touch controls.


**DevOps & deployment:**

Git & GitHub for version control
GitHub Actions to run CI checks like linting and build validation
Azure DevOps Pipelines to practice enterprise-grade CI workflows
Deployed as a static web application using GitHub Pages


The game runs completely client-side in the browser using JavaScript and Canvas. CI pipelines ensure that only validated, clean code is deployed, keeping the release process reliable and repeatable.
